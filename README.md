# Innovation Hacks Task 2 - Users, Projects & Tasks API

## 📌 Project Overview

This project is a REST API developed as part of the Innovation Hacks Full Stack Development Internship.

The API manages users, projects, and tasks and provides endpoints for creating, retrieving, updating, and deleting data.

## 🛠️ Tech Stack

- Node.js
- Express.js
- JavaScript
- CORS
- dotenv
- Thunder Client for API testing

## ✨ Features

- User management
- Project management
- Task management
- Task status management
- Input validation
- Error handling
- RESTful API endpoints
- Environment variable configuration
- Proper HTTP status codes
